# Section Header

Section Header — заголовок секции/группы контента: именует блок, задаёт иерархию, помогает сканировать и навигировать. **Отдельный переиспользуемый компонент:** вставляется в организм **«Остров»** как header и используется **самостоятельно** на любой странице, в шторке или форме.

Слоты: **Title** (+ опц. **Counter**) · опц. **Subtitle** · опц. **Trailing** (link / overflow).

> Модель — референс eBay Playbook «Section Header» (v4.1), адаптированный под канон Larixon Mobile.

---

## §1 Обзор

```
Черновики (3)                                   Все
Подзаголовок — контекст к группе
```

Заголовок именует логическую группу, опционально показывает счётчик, короткий подзаголовок-контекст и действие справа (переход «Все» или overflow-меню).

---

## §2 Когда использовать

**Использовать:**
- Заголовок логической секции/группы — на экране, **внутри острова** (как header), в Bottom Sheet, в форме.
- Когда группу нужно именовать и/или дать контекст (subtitle) и/или быстрый переход / действие.

**Не использовать:**
- Как заголовок всего экрана — для этого **Top App Bar v2** (тоже `H3 Medium`, свой компонент).
- Как заголовок **карточки** — там `H4 Medium 18` (крупная контентная) или `Body Dense 16` (компактная/списочная), по контексту.

---

## §3 Anatomy

```
┌───────────────────────────────────────────────┐
│ Title (Counter)                     [Trailing] │  ← Top line: Title row ↔ Trailing
│ Subtitle                                       │  ← строкой ниже, на всю ширину
└───────────────────────────────────────────────┘
```

Структура — **вертикальный стек**: `Top line` (горизонтальный, SPACE_BETWEEN: слева `Title row`, справа `Trailing`) и под ним `Subtitle` на всю ширину. **Trailing живёт на строке тайтла** (в `Top line`), поэтому привязан к заголовку и не смещается при многострочном сабе (см. §6).

**Слои:**
- **Title** (required) — имя группы. Опционально несёт инлайн-**Counter**.
- **Subtitle** (optional) — короткий контекст, **сгруппирован с тайтлом** (строкой ниже, зазор 4).
- **Trailing** (optional) — **Link** (переход «Все») или **Overflow** ⋮ (icon-кнопка, несколько действий). Один слот, не оба — см. §4a.

---

## §4 Варианты (свойства)

| Свойство | Тип | Значения | Назначение |
|---|---|---|---|
| **Trailing** | VARIANT | `None` / `Link` / `Overflow` | Нет / ссылочная кнопка («Все») / overflow-иконка (⋮) |
| **Counter** | BOOLEAN | `Off` / `On` | Инлайн-число у тайтла — «Черновики (3)» |
| **Subtitle** | BOOLEAN | `Off` / `On` | Подзаголовок под тайтлом |
| **Title** | TEXT | — | Текст заголовка |
| **Counter value** | TEXT | — | Значение счётчика |
| **Subtitle text** | TEXT | — | Текст подзаголовка |
| **Link label** | TEXT | — | Лейбл ссылки (дефолт «Все») |

---

## §4a Trailing — когда что

Один слот, **один аксессуар** (Link **или** Overflow, не оба):

| Значение | Когда | Примеры Larixon |
|---|---|---|
| **None** | Заголовок только именует группу, действий нет (самый частый). | «Характеристики» в острове, заголовок секции формы |
| **Link «Все»** | **Одно** очевидное действие — переход к полному разделу/списку. | «Рекомендации → Все», «Похожие объявления → Все» |
| **Overflow ⋮** | **Несколько** действий секции, либо вторичные/управляющие (сортировка, фильтр, режим выбора, скрыть, настроить, удалить, «не интересно») — прячем в меню. | «Сохранённые поиски» (сортировка/выбор/удалить), feed-блок рекомендаций (скрыть/почему вижу/настроить), «Мои объявления» (сортировка/массовые) |

- **Один аксессуар, не два.** Нужны и переход, и меню — обычно «Все» выигрывает (первичная навигация), остальное внутрь ⋮ или не в заголовок.
- **⋮ на уровне секции в мобилке — редкость.** Большинство заголовков = `None` или `Link`. Overflow оправдан там, где секция сама — управляемый объект (подборка, виджет-остров, лента).

## §5 Токены

### Title
| Параметр | Токен | Значение |
|---|---|---|
| Типографика | `Heading/H3 Medium` | 20/28, Inter Medium |
| Цвет | `Text&Icon/Primary` | — |

Контент: существительное / именная фраза, 1–3 слова (см. §7).

### Counter (у тайтла)
| Параметр | Токен | Значение |
|---|---|---|
| Типографика | `Heading/H3 Medium` | 20/28 — **тот же размер**, что тайтл |
| Цвет | **`Text&Icon/Secondary`** | приглушённый |
| Зазор Title↔Counter | `spacing/1` | 4 dp, инлайн |

> **Counter секции = приглушённое инлайн-число** (формат «(3)»), **не Badge**. Бейдж-счётчик (круг/пилюля) — паттерн Tabs / Notifications, не Section Header.

### Subtitle
| Параметр | Токен | Значение |
|---|---|---|
| Типографика | `Base/Body 2` | 14/20, Inter Regular |
| Цвет | `Text&Icon/Secondary` | — |
| Зазор Title↔Subtitle | `spacing/1` | 4 dp — **вплотную к тайтлу (один блок)** |

### Trailing
| Тип | Токен | Значение |
|---|---|---|
| **Link** — текст | `Base/Body 2 Medium` | 14/20 |
| **Link** — цвет (текст+иконка) | `Text&Icon/Link` | синий (Mobile DS: линк = синий) |
| **Link** — дефолтный лейбл | — | «Все» (для неочевидного — конкретнее: «Все камеры») |
| **Overflow** | `ButtonIcon` Ghost/32 + глиф `16 / ic_kebab` (⋮) | несколько действий — меню (см. §4a) |

### Layout / структура

```
Section Header (VERTICAL, gap 4)
├── Top line (HORIZONTAL, FILL, SPACE_BETWEEN) — Title row (+Counter) ↔ Trailing
└── Subtitle (FILL, на всю ширину, строкой ниже)
```

| Параметр | Значение |
|---|---|
| Top line | HORIZONTAL, ширина FILL, SPACE_BETWEEN; слева `Title row` (HUG), справа `Trailing` (HUG) |
| Subtitle | под `Top line`, на всю ширину (FILL), зазор к строке тайтла `spacing/1` (4) |
| **Выравнивание Trailing** | **оба трейлинга привязаны к строке тайтла, не к блоку:** Link — по **baseline** тайтла (`counterAxisAlignItems=BASELINE` на Top line); Overflow ⋮ — по **центру строки тайтла** (`CENTER` на Top line). При сабе в 1/2/3 строки trailing **не смещается** вниз. |
| Padding | 0 — внешние отступы задаёт **контейнер** (остров-Header / `section/*` spacing) |

## §6 Поведение

- **Перенос.** Title и Subtitle переносятся при нехватке ширины; цель — ≤ 2 строк.
- **Выравнивание trailing (ключевое).** **Оба трейлинга привязаны к строке тайтла, не к блоку:** Link — по **baseline** тайтла; Overflow ⋮ — по **центру строки тайтла**. Причина — действие ведёт на секцию, которую называет тайтл; пара «тайтл ↔ действие» читается на верхней линии. При сабе в 1/2/3 строки trailing остаётся на одной высоте (у тайтла), а не уезжает к середине/низу блока. У иконки нет базовой линии, поэтому её ровняют по центру строки тайтла (не baseline). **Не центрировать по всему блоку** (тайтл+саб) — тогда ⋮ уплывает вниз при сабе.
- **Группировка саба.** Subtitle строкой ниже тайтла (зазор 4) → тяготеет к заголовку, **не уплывает к контенту**. Зазор от хедера до контента держит **контейнер** (в острове — `section/title-to-content`, см. [island-card-spec](./island-card-spec.md)).

## §7 Контент (правила письма, по eBay)

- **Title** — существительное или именная фраза, **1–3 слова**, sentence case, без финальной пунктуации.
- **Counter** — число количества в группе, приглушённо, у тайтла («Черновики (3)»).
- **Subtitle** — короткая фраза; контекст **сверх** тайтла (фильтр, число результатов); **не повторять** тайтл; sentence case, без точки.
- **Link** — дефолт «Все»; для неочевидного назначения — конкретный лейбл («Все камеры»).

---

## §8 Использование

- **В организме «Остров»** — header острова = инстанс `Section Header` (единый источник заголовка, **включая подзаголовок**). Зазоры до контента — на стороне острова. См. [island-card-spec](./island-card-spec.md).
- **Самостоятельно** — заголовок секции на странице / в шторке / в форме.

---

## §9 Доступность

- `title` — heading-роль (`accessibilityTraits: .header` iOS / `heading` Android).
- Trailing — отдельная tappable-зона; минимум 44 dp обеспечивает контейнер/компонент.
